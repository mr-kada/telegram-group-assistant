# 🛡️ Telegram Group Helper Bot

A comprehensive Telegram group protection and management bot built with Telethon. It provides advanced anti-spam, anti-flood, captcha, media filtering, member management, and a full premium subscription system with payment integration.

The bot is designed to help group owners and admins keep their communities safe, clean, and well-organized — with an easy-to-use inline settings panel and a built-in admin dashboard.


## ✨ Features
- 🔐 **Group Protection** — Anti-spam, anti-flood, anti-porn, banned words, and alphabet filters.
- 🧠 **Human Verification (Captcha)** — Button-based captcha with customizable timer, penalty, and message.
- 👋 **Welcome & Goodbye Messages** — Fully customizable text, media, and inline buttons.
- 📜 **Group Rules** — Set rules via text, media, and URL buttons, viewable with /rules.
- 🔗 **Group Link Command** — Share the group link via /link.
- ⚠️ **Warning System** — Warn users with configurable max warns and punishments.
- 🚷 **Blocks & Restrictions** — Join/leave blocks, multi-join detection, blacklist, and bot restrictions.
- 📸 **Media Filtering** — Block or punish specific media types (photos, videos, stickers, etc.).
- 🌙 **Night Mode** — Schedule a time slot to silence or delete media automatically.
- 👥 **Roles & Permissions** — Co-founders, admins, moderators, cleaners, muters, helpers, and free users.
- 📊 **Advanced Statistics** — Track users, groups, messages, and subscription revenue.
- 💳 **Premium Subscriptions** — Tiered VIP plans with MyFatoorah payment gateway integration.
- 🎁 **Discounts & Offers** — Time-limited discount codes with usage tracking.
- 📢 **Broadcasting** — Send messages to all users or all protected groups.
- 🛠️ **Admin Dashboard** — Manage users, subscriptions, admins, and statistics from a private panel.
- 🌐 **Multi-Role Commands** — /ban, /mute, /kick, /warn, /pin, /staff, /info, and more.
- ⚙️ **Inline Settings Panel** — Configure every group setting without leaving the chat.
- 🗄️ **SQLite Storage** — Persistent user and subscription data.
- 🧾 **Subscription History** — View and export user subscription records.


## 🧾 Command Overview
*Basic Commands*

> /start — Start the bot
>
> /help — Show help menu
>
> /settings — Open group settings
> 
> /reload — Reload admin list
>
> /rules — Show group rules
>
> /link — Show group link

*Admin Commands*

> /ban, /unban, /mute, /kick
>
> /warn, /unwarn, /warns, /delwarn
>
> /pin, /delpin, /editpin, /repin, /pinned
>
> /info, /infopvt, /staff, /list, /list roles
>
> /send, /del, /geturl

*Role Management*

> /cofounder, /uncofounder
> 
> /admin, /unadmin
> 
> /mod, /unmod
>
> /cleaner, /uncleaner
>
> /muter, /unmuter
>
> /helper, /unhelper
>
> /free, /unfree


## ⚠️ Notes
*The bot must be promoted as admin in a group to manage it.*
